# Multilingual (vi / en / zh) – what changed

1. `npm i next-intl`
2. `next.config.mjs`:
   ```js
   import createNextIntlPlugin from "next-intl/plugin";
   const withNextIntl = createNextIntlPlugin("./src/i18n/request.ts");
   export default withNextIntl(nextConfig);
   ```
3. Copy `messages/` to the repo root (next to `src/`) and the files under `src/` over yours.

Adding a language: add `messages/xx.json`, then add it to `locales` and `localeMeta` in `src/i18n/config.ts`.

API routes now return error *codes* (`ROOM_NOT_FOUND`, `NOT_YOUR_TURN`, …); the client translates them via `useApiError()` and the `errors` namespace.
